Your year, drawn first, then built.

Contribution Lands is a Chrome extension that rebuilds the contribution graph on GitHub profile pages as an isometric New York City. Every day is a lot. Quiet days stay low, busy days rise into towers, and today is a building site.

Add to Chrome Source on GitHub

Free and MIT licensed · Chrome 111 or later · On the Chrome Web Store

Drawn from your contributions.

A-102 history Figure from Hairline by Lucas Marques, MIT

Each lot is one day of your contribution graph. The commits, pull requests, reviews and issues GitHub already counts for that day set its height, on one scale for everyone.

The extension reads the calendar on the profile you are viewing, and the public contributions page for earlier dates so streaks are complete. Nothing is sent anywhere else and nothing is stored but your settings. Privacy policy.

Works on any profile, yours or anyone's. The drawing above is the maker's own last 22 weeks, refreshed every night.

In your README

1 sheet · A-601
A-601 A real render from the Action, light version.

Your city, rendered every night

.webp · light and dark
  1. Add this workflow to your profile repository, the one named after your username.
  2. Run it once from the Actions tab. It then renders nightly.
  3. Show images/contribution-land-light.webp in your README, with contribution-land-dark.webp in a <picture> source for dark mode.
# .github/workflows/contribution-land.yml
name: Contribution land
on:
  schedule:
    - cron: "0 3 * * *"
  workflow_dispatch:
permissions:
  contents: write
jobs:
  render:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: jeanluciradukunda/contribution-lands@main
        with:
          theme: city-nyc
          output-dir: images
      - run: |
          git config user.name "github-actions[bot]"
          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
          git add images
          git commit -m "Update contribution land" || exit 0
          git push

Install it in one click.

3 steps · Chrome 111 or later

Contribution Lands is free on the Chrome Web Store. Prefer to build it yourself? The source and build steps are on GitHub.

  1. Add it to Chrome

    Open the Chrome Web Store listing and choose Add to Chrome.

  2. Open a profile

    Visit any GitHub profile. The graph is drawn and built as soon as the page loads.

  3. Pick a view

    Click the toolbar icon to switch between the flat graph, the land or both, and to set the scale, stats and motion.

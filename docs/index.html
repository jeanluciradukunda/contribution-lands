Your contribution graph, rebuilt as New York.

A Chrome extension for GitHub profile pages. Every day becomes a city lot: busy days rise into towers, quiet weekends turn into parks, and today is a building site that grows while you work.

Get the extension View the source

Public beta, free and MIT licensed. Chrome Web Store listing coming soon.

Five shades, five heights.

GitHub colours every day in one of five shades. Contribution Lands builds each shade at its own height, so a busy month reads as skyline and a quiet one as low-rise streets.

Stats in GitHub's own style

Put your city in your README.

A GitHub Action renders your land every night as a light and a dark image, ready for your profile README. Visitors see it whether or not they have the extension.

  1. Add this workflow to your profile repository, the one named after your username.
  2. Run it once from the Actions tab, then let it run nightly.
  3. Show images/contribution-land-light.webp in your README, with the dark image in a <picture> source for dark mode.
# .github/workflows/contribution-land.yml
name: Contribution land
on:
  schedule:
    - cron: "0 3 * * *"
  workflow_dispatch:
permissions:
  contents: write
jobs:
  render:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: jeanluciradukunda/contribution-lands@main
        with:
          output-dir: images
      - run: |
          git config user.name "github-actions[bot]"
          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
          git add images
          git commit -m "Update contribution land" || exit 0
          git push

Install

The Chrome Web Store listing is coming soon. Until then, the developer preview takes about two minutes to build and load.

Build it from source GitHub releases
  1. Clone and build 
    git clone https://github.com/jeanluciradukunda/contribution-lands.git
cd contribution-lands/extension
pnpm install && pnpm build
cp -r ../themes dist/themes
  2. Load it in ChromeOpen chrome://extensions, turn on Developer mode, choose Load unpacked and pick extension/dist.
  3. Open a profileVisit any GitHub profile, yours or anyone's. The graph is rebuilt as soon as the page loads.
